# 对接需求

我们的系统逐个触发组件，根据每一步的结果决定下一步。不需要工艺、订单、回调。

## 1. 接口：执行一个组件

- 输入：组件编码、组件参数、物料编号
- 返回：执行编号
- 组件的全部参数由我们填写（例如 PCR 每一步的温度、时间、循环次数）
- 执行结束后物料留在当前位置，下一次执行可以从该位置继续

## 2. 接口：查询一次执行

- 输入：执行编号
- 返回：状态（执行中 / 成功 / 失败）、失败原因、执行结果、仪器数据文件的下载地址

## 3. 组件清单

全部组件，每个组件的编码、作用、参数（名称、含义、单位、取值范围）。

## 4. 联调信息

接口地址、账号、已登记物料的编号和位置。
