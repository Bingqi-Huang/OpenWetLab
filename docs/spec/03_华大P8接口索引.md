> 根据《MGI PrepALL P8 IController 接口协议 V16》（适用 IController V1.7.0，485 页，原文在 `docs/`）自动整理，2026-11-17。只列出接口路径和说明；参数和返回值查原文或设备的 Swagger 页面。

## 要点

- **设备是什么**：一台独立的自动化液体处理工作站，内部有自己的移液臂、夹爪、温控模块、温控振荡模块、台面 PCR 模块、相机、门锁和灯。配套软件叫 ISW。
- **怎么控制**：ISW 在仪器电脑上提供 HTTP 接口，默认 `http://<仪器IP>:10090`，Swagger 页面 `http://<仪器IP>:10090/swagger/index.html`。接口全部是 `/v1/<模块>/<功能>`，大部分是 GET。
- **两种跑实验的方式**：上传 `.lhsprj` 工程文件后 `RunScript`；或者先加载工作台和台面文件，再加载脚本运行（也可以用 `RunScriptByContent` 直接传脚本内容）。运行中用 `Pause` / `Resume` / `Stop` 控制。
- **也支持单步操作**：扎吸头、吸液、排液、混匀、转移、内部夹爪抓取 / 放置、开关盖、温控、振荡等都有单独接口（`LhsInstrument` 下）。
- **设备状态** `GET /v1/LhsInstrument/GetInstrumentDeviceStatus`：100 启动后未复位、200 空闲、300 运行、400 暂停、500 错误、600 复位、700 阻塞。官方注明该接口可能阻塞，不要在关键线程里直接调用。
- **安全相关接口**：急停开关状态 `InstrumentGetEmergencyStopRealStatus`、门状态 `InstrumentCheckDoorStatus` / `GetSlidingDoorStatus` / `GetFlipDoorStatus`、门锁 `InstrumentOpenLock` / `InstrumentCloseLock`、移液臂回安全位 `MoveRobotToSafe`、停止全部硬件 `StopAllDevice`、仿真模式 `SwitchToSimulation` / `GetSimulationStatus`。
- **弹窗阻塞**：遇到需要人工处理的对话框时设备会阻塞，需要调用 `SetDialogDealInfo` 处理后才能继续。
- **请求来源控制**：配置项 `APIRquestControl` 会影响部分控制接口是否接受远程请求，远程调用前需要确认已开启。
- **厂商网关里已有对应驱动**：GW_005 上装有“MGI PrepALL P8 工作站驱动 v1.0.0”（http 协议）。**2026-11-18 起 GW_001 上也登记了 P8**，见下面“GW_001 上的 P8”。
